# Ideas and Feature Roadmap – ByteBites

Document for gathering ideas, feature concepts, and future enhancements for the **ByteBites** application.

---

## 🤖 AI Features & Smart Culinary Assistant
- [ ] **AI Macro Calculation**: Automatically analyze recipe title, ingredients, and quantities to estimate nutritional values (calories, protein, carbs, fats).
- [ ] **AI Image Generation**: Generate realistic preview photos for recipes based on ingredients and instructions when no photo is uploaded by the user.

## 🍳 Recipe Management & Cooking
- [ ] **Interactive Cooking Mode**: Step-by-step full-screen cooking assistant with timer and active ingredient checklist.
- [ ] **Servings Calculator**: Dynamic ingredient quantity scaling based on selected number of servings.

## 👥 Community & Social Interactions
- [ ] **Public Feed**: Global community feed displaying recipes added by all users.
- [ ] **Favorites & Bookmarks**: Hearting/saving public recipes to personal favorites list.
- [ ] **Author Profiles**: Display user profile (@username, display name) and list of recipes created by them.

## 🎨 UI / UX & Personalization
- [ ] **Cookbook Theme Design**: Warm parchment aesthetic with chapter-based table of contents.
- [ ] **Dark Mode / Cooking Theme**: High-contrast theme optimized for kitchen environments.

---

## 📝 Design Notes & Thoughts
* - Core focus for MVP v1.0 remains Clean Architecture, MVI presentation layer, and in-memory mock repository layer before integrating Spring Boot backend & AI services.
